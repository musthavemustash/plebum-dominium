Plebum Dominium · Passphrase Tool

Roll the dice.
We just look up the words.

A diceware passphrase is built from real dice rolls. Yours, not a computer’s. Roll five dice, type the number in, and this page maps it to its word on the EFF large wordlist. Six words make a passphrase worth roughly 77 bits of entropy.

Take this page offline before you roll

Checking whether this device is online…

The numbers you type here are the passphrase. The wordlist is public, so anyone who sees your rolls knows your words. Typing them on a networked device exposes them to malware, a compromised browser, and anything else watching the connection, which defeats the point of rolling physical dice for secrecy in the first place. Never enter rolls in an everyday browser session like this one. Run the mapper the way the guide runs key creation: from a saved copy, inside a separate offline Tails session.

  1. 1

    Download this page. The button above saves a single self-contained file: the whole wordlist is inside it, it makes no network references at all, and it holds none of your rolls. That downloaded file is the fully offline copy. This live page is not. It loads the site’s brand fonts from Google while you’re online. The saved copy never does. Put the file on the USB drive you boot Tails from.

  2. 2

    Boot Tails, and stay offline. Start the computer from the Tails USB, the same offline session the guide uses to make your keys, and don’t connect it to any network: no Wi‑Fi, no ethernet.

  3. 3

    Open the saved page in Tails, then roll. Type your numbers only there, once the indicator above reads offline. When you’re done, shut Tails down. It forgets everything.

How it works

  1. 1

    Roll five physical dice, or one die five times, and read them in order: 4-3-6-2-5 becomes 43625.

  2. 2

    Type the number into a slot. The word for that number appears beside it.

  3. 3

    Write the word on paper as you go, exactly as spelled. Repeat until all six slots are filled. Then write down the full passphrase and keep the paper somewhere safe.

There are no dice on this page. It contains no random number generator and will never roll for you. It is a lookup table, nothing more. The randomness comes from your hands and your dice, where it belongs.

Your passphrase

Copy it, then clear it. Paste the passphrase where it’s needed, write it on paper, then hit Start over so no trace of it stays on this screen. The mapper itself never sends or stores what you type. It only looks words up. The fully offline guarantee belongs to the downloaded copy: it references nothing on the network at all, not even the brand fonts this live page loads from Google, and it is saved blank, without your rolls. That saved copy, opened inside an offline Tails session, is the one to use.

Six words is the floor, not the ceiling. If this passphrase guards something you can’t afford to lose, roll a seventh word. each extra word multiplies the work of guessing it by 7,776.
