  1. Encrypt 1. Tails terminal ready. Tails is booted, networking off. The terminal is open. The tool and the map are on the Desktop. Nothing is typed yet.
  2. Encrypt 2. Run the tool, choose E. Type the command from the sheet. The banner shows the version. The menu offers E, D, and Q. E is encrypt.
  3. Encrypt 3. Paste map, passphrase twice. Paste the map, do not type it. The passphrase is typed, and only stars show. The words never appear. Entered twice, so a typo is caught.
  4. Encrypt 4. File saved, exit. The locked file is map.txt.gpg. Copy it to two USB drives. Delete the plain map. Empty the trash.
  5. Decrypt 1. Later boot, run the tool. On a later offline boot, run the same tool. The banner and menu are the same. This proves the locked file opens.
  6. Decrypt 2. Choose D, paste the armor. D is decrypt. Paste the full armor, through the END line. The tool waits for that line.
  7. Decrypt 3. Passphrase once, map restored. Decrypt asks once, not twice. The restored map must match the original. Check the first address.
  8. Decrypt 4. Clear the terminal, exit. Scrollback keeps the restored map until the terminal is cleared. Type reset when finished. Then the map is gone from the screen.
