Build the 2-of-3

Time45-60 min
DifficultyCareful
Steps9 sections

You will need: The three paper keys · Verified Sparrow

Three public keys go into Sparrow, and no seed ever touches this build. What comes out is the wallet map, which can watch the money and never spend it.

Safety first: Never enter seed words on an online computer. You will boot Tails four times: once per seed to copy its public key, then once more with no seed to build the vault.

Files used: Sparrow 2.5.5. Tails 7.16 or later 7.x (verified). Electrum 4.8.3 for the cross-check.

What you will do

  1. Boot Tails offline. Launch Sparrow from the terminal.
  2. Extract each seed's public key, one per boot.
  3. Build the 2-of-3 vault with no seed. Export the map.
  4. Confirm the first address on a second screen.

Step 1 / 7

Boot Tails. Networking stays off.

The entire sheet happens with networking Disabled. Check it on every boot.

Step 2 / 7

Open the terminal. Launch Sparrow.

Type these four lines, one at a time. Wait for the prompt to come back after each.

$ cd ~/Desktop

$ tar -xvf sparrowwallet-2.5.5-x86_64.tar.gz $ cd Sparrow $ ./bin/Sparrow</code></pre> <p>Wait 15 to 30 seconds. Sparrow opens. Type exactly. Spaces count. If a line turns red, stop.</p> </section>




Step 3 / 7


New wallet: 2 of 3, native Segwit.


File → New Wallet. Pick Multi Signature, Native Segwit, 2 of 3. The path must read m/48'/0'/0'/2'. Anything else: stop.


Check: The path reads exactly m/48'/0'/0'/2'.






Step 4 / 7


Keystore 1: Seed 1 in, public key out.


Keystore 1 → New or Imported Software Wallet → type Seed 1's 24 words. Export the xpub. Save it to the data USB as s1-xpub.txt. Close Sparrow. Shut down. Wait for a dark screen.






Step 5 / 7


Twice more. One seed per boot.


Boot again for Seed 2 → s2-xpub.txt. Shut down. Boot again for Seed 3 → s3-xpub.txt. Shut down.


Check: Three xpub files on the USB. One seed per boot, never two.






Step 6 / 7


Fresh boot. No seed. Build the vault.


Boot Tails again. Do not type any seed. New wallet → Multi Signature → Native Segwit → 2 of 3 → import the three xpub files. Confirm the path. Export the output descriptor to the data USB. That file is the wallet map.






Step 7 / 7


Confirm the first address on a second screen.


1 · Build in Sparrow. Write down the first receiving address it shows. The full string, not the QR code.


2 · Cross-check in Electrum. Rebuild the same 2-of-3 in Electrum offline from the same seeds. Compare the first address.


3 · Display on a second device. Load the wallet as watch-only (xpubs only, never seeds) on your phone or second computer. Compare character for character.


Check: All three agree. If anything differs, stop and rebuild. Do not fund the wallet until this matches.




Stop if: The path doesn't read m/48'/0'/0'/2'. Networking is on at any point. You're tempted to type a second seed without shutting down.
