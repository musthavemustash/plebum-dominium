This stick is the offline computer. It borrows the hardware, then forgets.

Networking off
  • One seed in memory

One computer, used twice. The first boot stays online and never holds a seed. The second boot is the Tails USB: networking off, exactly one seed, then a full shutdown. The seed lives in memory only. Shutdown wipes it.

Files used: Tails 7.16 or later 7.x (verified).

What you will do

  1. Prepare two USBs: Tails and data.
  2. Boot Tails offline for each seed session.
  3. Shut down fully between sessions.

Step 1 / 3

Prepare the two USBs.

Download Tails only from the official site. Check the signature and checksum before writing. Write it with the official installer, label it TAILS. Do not create Persistent Storage. The data USB gets only files that already passed the checks.

Check: Tails USB is labeled. Data USB has only verified files.

Step 2 / 3

Boot offline. Do the work. Shut down.

Boot the Tails drive. Networking Disabled on the welcome screen, before the desktop. Copy only the file that session needs from the data USB. Do the work. Copy the result back. Shut down fully. Dark screen before the drive comes out.

Check: Networking was Disabled before the desktop appeared. One seed per session, never two.

Step 3 / 3

Know what "airgapped" means.

Yes: Networking Disabled on the welcome screen. Files cross on the data USB. The online computer never holds a seed.

Not airgapped: Turning networking off after a program opened. A photo of a seed. A password manager or cloud note as backup.

Stop if: Two seeds in one session. Networking was on at any point. A seed was photographed or typed anywhere except the offline session.
