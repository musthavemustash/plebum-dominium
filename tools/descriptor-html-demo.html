  6. Decrypt 2. Choose Decrypt, paste the armor. Decrypt a map is the mode. Paste the full armor, through the END PGP MESSAGE line.
  7. Decrypt 3. Passphrase once, map restored. Decrypt asks once, not twice. The restored map appears. It must match the original.
  8. Decrypt 4. Check the first address. The first address is highlighted. It must match what was written down. Then close the page.
