Practice spend, three ways to move

Three animated concepts for the signing graphic — the dust payment that takes two signatures before it broadcasts. A splits the file in half across the airgap (revised per your note) — now in three versions: A the join, A2 the commuter, A3 merge on the line. B turns two physical keys in a lock. C dives the file across the airgap twice. Tell me which one lands — or what to steal from each.

The conveyor, rebuilt around your idea: the PSBT starts as half a file up in the online world. It dives across the airgap line — the offline half slides in, the file locks whole with a flash — then it visits each seed for its signature before rising back up to broadcast.

Concept A3 · v2

The filling file

Concept B

Two keys turn

Two physical keys slide in and turn, one after the other. The shackle lifts only when both have turned — then the broadcast goes out. The 2-of-3 idea, made literal.
