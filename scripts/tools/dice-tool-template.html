Plebum Dominium

Dice converter

Dice rolls become 24 words. Everything happens in this page, offline. Nothing you type leaves it.

1Record the rolls

Roll five dice. Enter each face left to right, the same way every shake. Faces 1 to 4 are kept as bits. Faces 5 and 6 are skipped, roll those dice again. Stop at 128 pairs.

1 = 002 = 013 = 104 = 115 6 = skipped
Pairs 0 / 128
Bits 0 / 256

256 bits recorded. The 24 words are below.

2The 24 words

The words appear when 256 bits are recorded. Word 24 is the check. It is not chosen, and it is never fixed by hand.

    Or paste a binary string

    The offline Python tool accepts 256 bits or more. Longer input is hashed down to 256. This box does the same.

    3Validate

    Paste the 24 words from the other tool. Two tools, same bits, same 24 words. The check has to pass and every word has to match. If anything differs, stop.

      Online

      Stop. This computer is online.

      Seed words are never typed on a computer that can reach the network. A connected machine can leak every keystroke to malware, a bad extension, or the network itself. One leak burns the words, and burned words mean new dice, new words, new plates.

      Close this page. Boot Tails with networking set to Disabled, or disconnect this machine from the network, then open the file again. If this page still says Online on a machine you believe is offline, trust the page. Something is still connected.
